# Source harvest form

Gist: a one-page form for writing down where each bit of quarterly slide text actually came from, using the rules the CRC prompt library already locked in rather than new ones.

Fill it in wherever you are — it needs no tools. Transcribe into the `Sources` sheet
afterwards. The sheet holds POINTERS, not documents: what a thing is and where it lives,
never its contents.

**Standard this follows:** the CRC SAAFE Prompt Library — Global Prompt Tenets, and the
Data Integrity & Field Governance Rules (locked 9 May 2026). Where this form and the
library disagree, the library wins; it is tested and in use, and this is downstream of it.

---

## What counts as a source here

A source is a pointer to something that was read. That is the whole definition — there
is no type hierarchy to learn.

The library's Verbatim Protection Rule is deliberately NOT carried over, and this is
worth stating so nobody re-adds it later. That rule exists because the Family Tree puts
source data (cols A–Z) and synthesised output (cols AA+) in the same grid, where one
paste can destroy the source. It is a fix for a layout problem. This model has no such
layout: the register holds slide fields only, and the Sources sheet holds pointers and
refuses content by design. Commonwealth text never enters the register, so there is
nothing in the register to protect.

Where the two surviving pieces of that rule already live:

- **A field that must show given wording, not drafted wording** → `FieldSpec.Kind =
  Static`, which switches drafting off for that field. Already built.
- **Do not contradict or reframe the source** → the Field Spec's `Do NOT` column, which
  already carries clauses of exactly this kind.

Gist: the "don't overwrite the official wording" rule was solving a spreadsheet-layout problem that this design doesn't have.

One thing still worth noticing when you fill the form in: deck-sync's drafting prompt
says "read the workbook and the existing text in column C", so most drafted text traces
to the register itself. Citing a SharePoint report for a sentence actually synthesised
from column C is a false trace — it looks like stronger evidence than it is.

## The rubric — what earns a row

From the library's tenets, not invented here.

| # | Test | From | Fails when |
|---|------|------|-----------|
| 1 | **It traces to something specific** — a named cell, column, or retrievable document | Tenet 1 | "background reading", "what Kate said" |
| 2 | **Nothing was invented, estimated or approximated** from it | Tenet 1 | the figure was rounded, inferred, or filled from memory |
| 3 | **It was read before generating**, not recalled afterwards | Tenet 3 | reconstructed at the end of the quarter |
| 4 | **Someone who is not you can retrieve it** from the locator | Interpolation rule 1 | "the drive", "SharePoint" |

Fails any of these → it is not a source. Tenet 1 gives you the alternative: **`[TBC]`**.
An honest gap beats a citation that will not hold.

**Period:** does the document say something true only of one quarter, or true whenever
read? Contract or program plan → `All periods`. A quarter's own report → that quarter.
Publish reports a cross-period citation and lets it through, so this is a record-quality
call, not a gate.

## The form

One block per source. Copy it as many times as you need.

```
SOURCE ---------------------------------------------

ID              S__            (next free number — the Sources sheet tells you)

What it is      [name it as it is actually named, not as you think of it. If
                 it is a spreadsheet, name the sheet and column too.]

Type            [Report | Contract | Plan | Minutes | Data | Notes | Paper]

Where it lives  [specific enough for someone else to open it:
                 SharePoint > Reporting > Q4F26 > filename
                 or: <workbook> > <sheet> > <column>]

Applies to      [All periods  |  Q4F26  |  Q1F27]

Generated by    [which library prompt produced the text that cites this, and
                 when: "Prompt 18, 2026-08-09". Required by the Interpolation
                 Permission Rule -- a synthesised field must document the rule
                 that generated it. Leave blank only if a person wrote it.]

Notes           [what it supports, and what it does NOT -- superseded, draft
                 only, covers 12 of 43 projects. One line each.]

Added           [today's date — nothing fills this in for you]

RUBRIC          [ ] traces to something specific   [ ] nothing invented
                [ ] read before generating         [ ] retrievable by others

CITED BY        [projects/fields you expect to cite it — pencil, not a
                 commitment]
```

## Transcribing into the sheet

`Sources` lives in the register workbook. Rows start at **row 6**; row 5 is the header.

| Col | Header | From the form | Notes |
|-----|--------|---------------|-------|
| A | ID | `ID` | short and stable — `S07`, not a label |
| B | What it is | `What it is` | |
| C | Type | `Type` | free text; keep to the shortlist so it stays sortable |
| D | Where it lives | `Where it lives` | |
| E | Notes | `Generated by` + `Notes` | put the prompt reference first |
| F | Added | `Added` | **manual — no code writes this** |
| G | Applies to | `Applies to` | dropdown, fed from the register's own periods |

Then put the ID in **column G of the drafting sheet** for each row that used it,
comma-separated: `S07,S09`.

Gist: write each source down once in the Sources tab, then type its short code next to every project that used it.

`Generated by` has no column of its own, so it rides at the front of `Notes`. If a real
harvest shows it earns one, that is a small change to `Sources.bas` — but do the harvest
first and let the need show up, rather than adding a column on a guess.

**Never rebuild the sheet by hand.** Rows accumulate and survive every drafting refresh
by design — a source outlives the field it was used for. Add rows; don't tidy them.

**An ID that does not exist is reported at publish.** It will not stop the publish. It
means the record is wrong, which is worse than it looks: a citation pointing nowhere
reads as provenance and isn't.

## Before you start: clear the scaffolding

`S01`–`S06` are **not real documents**. Invented 2026-08-08 to exercise the citation
check, prefixed `EXAMPLE (not a real document)`. They also have the Applies-to value
wrongly duplicated into `Added`, which is a fair illustration of why they should not
survive contact with real data.

**They are cited, on real rows.** `TPL_ABOUT_BODY` column G carries citations on 37
project rows — `S01,S03`, `S01,S02` and so on — against real SAAFE project text. So
right now the drafting sheet shows fabricated provenance next to genuine content, which
reads as a record and is not one. (`TPL_KEY_EVENTS_BODY` is clean; header only.)

Clearing it is two jobs, not one:

1. Delete rows 6–11 of the `Sources` sheet.
2. Blank column G on `TPL_ABOUT_BODY` for all 37 rows.

Doing only the first is worse than doing neither: the citations survive, now pointing at
IDs that no longer exist, and publish reports them as unknown refs on every run.

An earlier version of this file claimed that column was empty. It was never opened —
the claim was assumed, in a document about provenance, which is the same error the
document exists to prevent.

## Two open questions this harvest will answer

**Can Copilot reach a document from a path?** Answerable at work in a minute. If it can,
a `Document` citation is a real trace. If it cannot, it is an attestation — "I read
this" — still worth recording, but weaker, and the `Kind` column above is what keeps
that distinction visible instead of buried.

**Are three fields missing from sync?** The project slide carries five prose panels —
Strategic Alignment, About, Problem, Project Progress, Key Events. The register carries
`ABOUT_BODY` and `KEY_EVENTS_BODY` only. The library has locked definitions for all
five (Prompt 18). Whether the other three are deliberately out of scope or were simply
never marked is worth settling before a real quarter, because a field outside sync is a
field that silently keeps last quarter's text.
